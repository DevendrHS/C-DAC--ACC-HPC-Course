1.What is an HPC cluster?
 it is a group of powerful  nodes, connected through a high-speed network 
 and working together to solve large computational problems.

2.What is a Compute Node?
individual computer/server inside a hpc cluster that perform calculation

3.What is a CPU Socket?
A CPU socket is the physical connection on a motherboard where a CPU processor is installed.

Why:
It allows the processor to communicate with memory and other components of the system.


4.What is Cache Locality?
Cache locality means keeping frequently or recently used data close to the CPU so it can access that data quickly.


5.What is NUMA?
 NUMA stands for Non-Uniform Memory Access.

In NUMA systems, different CPUs have different distances/access times to different parts of memory.
Imagine two students:

Student A has a book on his own desk → fast access.
Student A needs a book from Student B's desk → slightly slower.

Similarly, a CPU can access its local memory faster than remote memory.

Remember:

NUMA = Memory access time depends on where the memory is located.


6. What is OpenMP?
OpenMP is a programming API used for shared-memory parallel programming.

It allows a program to divide work among multiple CPU threads.


8. What is an MPI Rank?
An MPI rank is a unique ID assigned to an MPI process.


9. What is a Thread?
A thread is a small unit of execution within a process.

Multiple threads can execute different parts of a program concurrently.

10. What is Parallel Scalability?
Parallel scalability describes how effectively a program improves its performance when more processors, cores, or nodes are added.



11. What is Communication Latency?

In distributed HPC systems, processors/nodes frequently exchange data. 
High latency can slow down the application.

17. What is RDMA?

What:
RDMA stands for Remote Direct Memory Access.

It allows one computer to access/read/write memory on another computer with minimal involvement of the remote CPU and operating system.

Why:
It reduces communication overhead and latency, which is very useful in HPC.


8. What is a GPU Accelerator?
A GPU accelerator is a GPU used alongside the CPU to accelerate highly parallel computational tasks.
Why:
GPUs contain many processing units and can perform many similar operations simultaneously.

CPU:
Pixel 1 → Pixel 2 → Pixel 3 → Pixel 4
        sequential/limited parallelism

GPU:

Pixel 2 ├→ Many operations simultaneously

Pixel 4 ┘

19. What is Heterogeneous Computing?
means using different types of processors together, such as CPUs and GPUs,
 to execute different parts of a workload.



20. Why is Workload Characterization Important in HPC?
Workload characterization means understanding the characteristics of an application/workload,
 such as:

How much computation it needs
How much memory it needs
How much data it moves
How much communication it requires
How parallel it is

Why:
Different applications need different hardware and optimization strategies.

1. HPC Hardware Architecture
HPC hardware architecture describes the physical components used to build an HPC system, such as CPU, memory, storage, compute nodes, GPU accelerators, and network interconnects.

Why:
These components work together to provide high computational performance.



2. Modern CPU-GPU HPC Systems--
Modern HPC systems often combine CPUs and GPUs. 
The CPU handles general-purpose/control tasks, while GPUs accelerate highly parallel computations.

Different processors are suitable for different types of workloads.
