# Module 1: Introduction to C Programming

## What is C?

C is a general-purpose programming language developed by Dennis Ritchie in 1972 at Bell Labs.

It is known as a middle-level language because it combines the features of both low-level and high-level programming languages. C allows programmers to work closely with computer hardware while also providing structured programming features.

---

## Why is C Used in This Course?

C is usually taught first because it provides a strong foundation for learning other programming languages such as C++ and Python.

### 1. Builds Programming Logic

C helps students understand:

* Variables
* Data Types
* Operators
* Conditional Statements
* Loops
* Functions

These concepts are common to almost all programming languages.

### 2. Understanding Memory

C provides direct access to memory through pointers. This helps students understand:

* Memory allocation
* Memory addresses
* Program execution

### 3. High Performance

C programs are compiled into machine code, making them very fast and efficient.

### 4. Foundation for C++

Most of the syntax of C++ comes from C. Learning C first makes C++ easier to understand.

### 5. Useful for Technical Careers

Knowledge of C is valuable in:

* Software Development
* System Programming
* Cybersecurity
* Blockchain Development
* High Performance Computing (HPC)

## Structure of a C Program

```c
#include <stdio.h>

int main() {
    printf("Hello World");
    return 0;
}
```

### Explanation

1. #include <stdio.h>

   * Includes the Standard Input Output library.

2. int main()

   * Entry point of the program.

3. printf()

   * Displays output on the screen.

4. return 0;

   * Indicates successful execution of the program.
