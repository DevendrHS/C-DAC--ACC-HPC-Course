What is the Kernel?

Suppose you run:

ls

You type this into the terminal.

The process is approximately:

You type: ls
       ↓
Shell reads the command
       ↓
Shell finds the ls program
       ↓
Program asks Linux for directory information
       ↓
Linux kernel communicates with storage
       ↓
Information is returned
       ↓
Terminal displays files

The important concept is:

Applications generally request services from the kernel rather than directly controlling hardware.

This communication happens through mechanisms including system calls.


Linux vs Linux Distribution

If Linux is the kernel, then what is Ubuntu?

Ubuntu is a Linux distribution.

A distribution packages:

Linux Kernel
+
System utilities
+
Package manager
+
Libraries
+
Desktop environment (optional)

Applications
