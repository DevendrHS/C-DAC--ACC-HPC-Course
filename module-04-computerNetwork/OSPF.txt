. its a link state protocol.
.Administrative Distance-- value 110
. it support VLSM  and CIDR 
.hello timer / update timer/ 0 second
. dead timer --40 sec
. it bring Area OSPF concept.
.it support unlimited hop count




STAGES OF OSPF:-
1)DOWNSTATE->PROCESS IS NOT STANDARD. HELLO PACKET NOT sent
2)initial state->hello packet sent .no neighbour table has been  creates.
3)two way state ->bi directional communication started  and neighbour 
4. exstart-- both router chech rouder id whose is greter then it  will first dend
5. exchange--both router send data each other (data is shared between them is LSD link state dadtabase)

    3 table are in there ---
    Neighbour table--- has information /hello packet of their router
    Routing-- all the possible path reach destination
    database-- summary of information of other router

    6. load state--both router compare summary and if tranfer some extra data then they send
     link state request to other request and other router gives link state update to the router

     7. full state--both router have complete database of each other and communication is success full
